Criar QR Code para links e textos

Gere um QR Code a partir de um endereço de site ou de um texto. QR Codes podem ser usados em materiais impressos, apresentações, cardápios, cartões e compartilhamento rápido de informações.

Passo a passo

1. Digite ou cole o endereço ou texto no campo. 2. Escolha o tamanho da imagem. 3. Clique em Gerar QR Code e use o botão de download exibido no resultado. Teste o código com a câmera de um celular antes de imprimir.

Perguntas frequentes

Posso criar QR Code para qualquer texto? Sim, desde que o conteúdo caiba na capacidade do código; textos maiores geram códigos mais densos.

O QR Code expira? O código gerado é uma imagem estática. Ele não expira, mas um link codificado pode deixar de funcionar se o endereço de destino mudar ou sair do ar.
