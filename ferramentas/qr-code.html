Gerador de QR Code

Gere um QR Code para um endereço web ou qualquer texto.

Como usar

Gere um QR Code para um endereço web ou qualquer texto. Selecione ou insira seu conteúdo, ajuste as opções disponíveis e execute a operação. Em ferramentas de arquivo, o processamento é realizado no próprio navegador sempre que possível.

Privacidade

Os arquivos selecionados pelas ferramentas de imagem são processados localmente. Fechar ou atualizar a página limpa os dados temporários desta sessão.
